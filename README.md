# Wardrobe Sense

Aplikasi mobile **AI Personal Stylist & Curated Fashion** berbasis Flutter yang menghubungkan pengguna dengan rekomendasi outfit dan produk fashion dari UMKM lokal.

## Requirements

- Flutter SDK >= 3.0.0
- Android Studio untuk Android
- Xcode untuk iOS (Mac)

## Menjalankan Project

```bash
flutter pub get
flutter run
